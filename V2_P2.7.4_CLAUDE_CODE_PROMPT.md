### Helper
```ts
// src/hooks/useCleanCategories.ts
import { useLiveQuery } from 'dexie-react-hooks'
import { useDb } from '@/contexts/DbContext'

export function useCleanCategories() {
  const db = useDb()
  const accounts = useLiveQuery(() => db?.accounts.toArray() ?? [], [db])
  const categories = useLiveQuery(() => db?.categories.toArray() ?? [], [db])

  if (!accounts || !categories) return undefined

  const accountNamesLower = new Set(
    accounts.filter(Boolean).map(a => a.name.toLowerCase())
  )
  return categories
    .filter(Boolean)
    .filter(c => !accountNamesLower.has(c.name.toLowerCase()))
}
```

### Steps
1. Create helper file
2. For each consumer: replace `useLiveQuery(() => db.categories.toArray())` with `useCleanCategories()`
3. **Per Rule 4: pause before applying to chart components** (CategoryTrend, CategoryComposition, FinancialIdentityCard, SeasonalHeatmap, CorrelationWeb) — these may have downstream behavior changes (e.g., totals reduce when categories hidden). Get explicit user confirm before touching charts.

### Edge cases

- Categories table empty / accounts table empty → return original (don't filter to empty)

## C7 — F1 + F2: Tri-state account classification + NetWorth rewrite

### Scope
**LARGEST commit.** Replace 2 toggles with 1 segmented control. Migration resolves "both true" anomaly. NetWorth calc uses ONLY isLiability for liability classification — no negative-balance fallback. Liability accounts NEVER counted as assets even if balance positive.

### Design decision
Keep dual fields (`includeInNetWorth`, `isLiability`) with mutual exclusion enforced in UI + migration. **No new schema field, no Dexie bump.** Tri-state mapping:
- **Liability** → `isLiability=true, includeInNetWorth=false`
- **Asset** → `isLiability=false, includeInNetWorth=true`
- **Neither** → `isLiability=false, includeInNetWorth=false`

### Files
- `src/components/settings/AccountsTable.tsx` — replace 2 toggle columns with 1 segmented control
- `src/components/stats/NetWorth.tsx` — calc rewrite
- `src/components/AppContent.tsx` (or boot helper) — one-shot migration
- Verify consumers (grep): `src/hooks/useSafeToSpend.ts`, `src/components/home/BelowThresholdCard.tsx`, `src/components/home/SpendComparisons.tsx`, anywhere else reading the two flags

### Steps

**Migration (run once on boot):**
```ts
const flag = await db.appSettings.where('key').equals('triStateMigratedAt').first()
if (!flag) {
  const accounts = await db.accounts.toArray()
  for (const acc of accounts.filter(Boolean)) {
    if (acc.isLiability && acc.includeInNetWorth) {
      // tiebreaker: liability wins (D040)
      await db.accounts.update(acc.id!, { includeInNetWorth: false, updatedAt: Date.now() })
    }
  }
  await db.appSettings.put({ key: 'triStateMigratedAt', value: new Date().toISOString() })
}
```
